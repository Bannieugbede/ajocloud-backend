# Share links

Everything a member shares is a short link on the public website. With the app
installed the link opens it; without, the page describes what was shared, lets
the person join on the web, and offers the app. Social apps read the page's
preview, so the link unfurls with the group's name and amount.

| Link                        | What it is           | Code                                      |
| --------------------------- | -------------------- | ----------------------------------------- |
| `ajocloud.com/g/<code>`     | An Ajo group         | 10-char invitation, or 7-char public code |
| `ajocloud.com/p/<code>`     | An Akawo pool        | 8-char join code, or 7-char public code   |
| `ajocloud.com/f/<code>`     | A Food Ajo programme | 7-char public code                        |
| `ajocloud.com/r/AJO-XXXXXX` | A member's referral  | Referral code                             |

The length says which kind of code a link carries, so a code is only ever looked
up as the kind it is.

## Public codes

Every Ajo group, Akawo pool and Food Ajo programme has a permanent 7-character
`shortCode`, generated by the database (`share_code(7)` in the `short_links`
migration) from the referral code's alphabet, which leaves out 0/O, 1/I/L and
8/B. It is not a secret and it never changes.

A public code on its own admits nobody. For an Ajo group or Akawo pool it works
only while the organiser has **listed** the group:

- `PATCH /api/v1/ajo-groups/:groupId/listing` `{ "listed": true }` — the
  group's active administrator only, and only while the group still takes
  members (`DRAFT` or `OPEN`). Unlisting is always allowed.
- `PATCH /api/v1/akawo/pools/:poolId` `{ "publiclyListed": true }` — the
  organiser only.

A listed group's page is indexed, appears in the sitemap, and can be joined from
without an invitation: `POST /ajo-groups/:groupId/join` and
`POST /akawo/pools/join` accept the public code in place of an invitation or
join code. Unlisting takes effect at once. The public code of an unlisted group
is reported exactly like a wrong code, so it reveals nothing.

Food Ajo programmes are public whenever they are `OPEN` or `ACTIVE`, so they
need no listing.

## Invitation codes

Ajo invitations are 10 characters from the same alphabet (about 48 bits),
drawn from `crypto.randomBytes` and stored only as a peppered HMAC. They are
compared case-insensitively. Invitations issued before short links are 43
characters of base64url and stay redeemable, case-sensitively, until they
expire. Every public lookup of a code is rate limited to 20 a minute.

## Public endpoints

All unauthenticated and rate limited:

- `GET /api/v1/public/ajo-groups/:code` — an invitation or a listed group.
  `kind` is `invitation` or `listed`; only a listed group carries its
  `shortCode` and `description`. `GET /api/v1/invitations/:code` is the older
  address of the same thing.
- `GET /api/v1/public/akawo-pools/:code` — a join code or a listed pool's
  public code. `kind` is `code` or `listed`.
- `GET /api/v1/public/food-programmes/:idOrCode` — by public code, or by id for
  links shared before short codes.
- `GET /api/v1/public/listings` — what search engines may index: listed Ajo
  groups still taking members, listed open Akawo pools, and open or active Food
  programmes. Codes, names and dates only, at most 10,000 of each.

The website builds links from `ADMIN_WEB_URL`, the site root; a trailing
`/admin` is stripped (`src/common/links/public-web-url.ts`).
