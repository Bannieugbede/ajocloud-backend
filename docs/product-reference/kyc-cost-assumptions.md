# KYC cost assumptions

> Unverified planning assumptions requiring current provider confirmation and commercial agreement.

No provider price in a draft, product comparison, or historical quote is production configuration. BVN, NIN/vNIN, bank inquiry, face match, liveness, and address-verification costs must be verified against current official documentation and the organisation's agreement, then stored as effective-dated internal planning or fee data with access controls. This repository contains no approved KYC prices.
